# 🏦 Banking Analytics Dashboard

## 🔍 Overview

This project analyzes banking loan data to identify loan performance, risk, and customer trends using SQL, Power BI, and Tableau.

---

## 🚀 Key Features

* Loan application analysis
* Funded vs received amount
* Interest rate trends
* Good vs Bad loan classification
* Interactive dashboards

---

## 🛠️ Tools Used

* SQL (MySQL)
* Power BI
* Tableau
* Excel
